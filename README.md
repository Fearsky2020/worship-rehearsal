# Worship Rehearsal V2.5 — Score Source Preview

V2.5 在 V2.4 多谱型搜索基础上，把五线谱和简谱真正接入排练工作流。

## 新功能

每个候选谱现在可以：
- 标注谱型：和弦谱 / 五线谱 / 简谱
- 标注来源
- 保存 Key
- 保存来源链接
- 指定预览方式
- 在候选列表直接点“预览”
- 采用后继续进入现有排练编辑器

## 预览方式

候选支持：
- 自动判断
- 网页链接
- 图片
- PDF
- 文字谱

自动判断会根据链接扩展名和候选内容选择预览方式。

### 图片
直接在页面内显示 PNG/JPG/WebP/GIF。

### PDF
使用浏览器 iframe 预览 PDF。

### 网页
尝试 iframe 预览来源页面。
部分网站会通过 X-Frame-Options 或 CSP 禁止嵌入，这种情况请使用“打开来源”。

### 文字谱
简谱文字、和弦谱、Music-AI 文本可直接在页面内预览。

## 保留功能

- 三种谱型搜索
- 来源标注
- 可编辑排练版
- ±1 半音
- 恢复原谱
- 保存排练版
- PDF 导出
- A/B Loop
- 本地歌曲库
- Music-AI 后备候选

## 后续方向

真正的五线谱 / 简谱结构化编辑器需要处理 MusicXML、SVG/Canvas 或专门的数字谱数据结构，后续单独实现。
