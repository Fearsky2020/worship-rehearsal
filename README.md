# Worship Rehearsal V2.4 — Multi-score Search

V2.4 保留 V2.3 的可编辑排练版、移调和 PDF 导出，并升级找谱流程。

## 新功能

找谱区域现在分为三种谱型：

1. 和弦谱
2. 五线谱
3. 简谱

识别 YouTube 歌名后，可切换谱型并生成针对当前歌曲的搜索入口。

### 和弦谱关键词
- 歌曲名 + 和弦谱
- 歌曲名 + chords
- PraiseCharts
- Chordify
- Ultimate Guitar
- YouTube 教学

### 五线谱关键词
- 歌曲名 + 五线谱
- 歌曲名 + sheet music
- 歌曲名 + score
- PraiseCharts
- MuseScore
- 图片搜索

### 简谱关键词
- 歌曲名 + 简谱
- 歌曲名 + 歌谱
- 歌曲名 + 数字谱
- 歌曲名 + 敬拜 + 简谱
- 图片搜索
- YouTube 教学

## 候选谱

每个候选现在保存：
- 谱型
- 来源
- Key
- 来源链接
- 可选的可编辑文本内容

只标注来源和谱型，不对来源做价值判断。

## 保留 V2.3 能力
- 原谱保留
- 我的排练版
- 自由编辑
- ±1 半音移调
- 恢复原谱
- 本地歌曲库
- A/B Loop
- PDF 下载
- Music-AI 后备候选

## 当前边界

五线谱和图片形式简谱在 V2.4 中主要作为“搜索与候选来源”保存。
真正的五线谱 / 简谱可视化编辑器将在后续版本处理。
