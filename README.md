# Worship Rehearsal V2.3 — Editable Rehearsal Chart

V2.3 在 V2.2 “先搜现成谱”的基础上加入真正可用的排练编辑器。

## 新功能

- 采用候选谱后自动建立“我的排练版”
- 原始候选谱独立保留
- 自由编辑：
  - 歌名
  - Key
  - BPM
  - 拍号
  - 和弦/段落文字
- ±1 半音移调会直接作用于当前编辑版
- 一键恢复原谱
- 保存排练版
- 复制文本
- A4 PDF 下载
- 歌曲库保存排练版

## PDF

PDF 完全在浏览器端生成，不上传排练谱内容到服务器。

使用：
- html2canvas 1.4.1
- jsPDF 4.1.0

通过先渲染排练版页面再写入 PDF，避免中文直接写入 jsPDF 标准字体时出现乱码。

## 当前产品流程

YouTube → 识别歌名 → 搜现成谱 → 记录候选 → 采用 → 自由编辑 → 移调 → 保存 → 下载 PDF

Music-AI 继续作为后备候选。
