# Worship Rehearsal V2.7 — Interface Cleanup

V2.7 不增加新功能，重点重做信息层级和手机体验。

## 界面调整

页面按真实使用顺序重排：

1. 粘贴 YouTube
2. 找谱
3. 预览
4. 编辑排练版
5. 简谱工具
6. A/B 排练
7. 歌曲库
8. Music-AI 高级后备

## 减少视觉混乱

- 第一屏只保留 YouTube 输入和状态
- 搜谱候选录入默认折叠
- 简谱编辑器默认折叠
- A/B Loop 默认折叠
- 歌曲库默认折叠
- Music-AI 默认折叠
- 主要编辑器保留在主流程
- 卡片、按钮、间距、标题层级重新统一
- 手机端减少横向拥挤

## 智能展开

采用“简谱”候选时，会自动展开简谱编辑器。

## 功能保持

- 和弦谱 / 五线谱 / 简谱搜索
- 来源预览

- 自由编辑
